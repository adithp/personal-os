# Projects

## Purpose
Manage freelance, college, personal, and software projects in one place.

## Screens
- Project list with status and progress.
- Project page: overview, tasks (list and kanban), milestones, timeline, notes, files, emails, events, client, time tracking, income and expenses, progress dashboard.

## Features
Projects, tasks, subtasks, milestones, deadlines, status, kanban, lists, timeline, client information, notes, documents, files, time tracking, project expenses, project income, progress tracking, dashboards. Everything linked to the project appears on its page.

## Actions
projects.list, projects.get, projects.create, projects.update, projects.status

## AI
Answers "What is the status of my freelance projects?" using tasks, deadlines, emails, and notes.

## Done when
Each project page shows everything about that project, and the AI reports status correctly.
