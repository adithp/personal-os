# Drive (Google Drive)

## Purpose
A central interface for my cloud files.

## Screens
Folder browser, search, file preview (images, PDF, Google Docs export), upload, download.

## Features
Browse, search, upload, download, open, manage, preview; link files to projects and notes.

## Actions
drive.search, drive.list, drive.read_text, drive.upload

## AI
Searches and reads text from Drive files when asked.

## Done when
I find and attach Drive files to projects and notes without opening Drive.
