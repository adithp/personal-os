# Finance

## Purpose
Track income and spending.

## Screens
Transactions list, add transaction, categories, budgets, savings goals, monthly report with Recharts charts, finance dashboard.

## Features
Income and expense tracking, transactions, categories, budgets, savings, goals, monthly summaries, spending analysis, reports, recurring transactions, CSV statement import with AI categorization. All amounts in INR (paise).

## Actions
finance.add_transaction, finance.summary, finance.budget_status

## AI
Answers "How much did I spend this month?" and "Where am I spending the most money?"

## Done when
All my spending is tracked here and the monthly report is accurate.

## Built (Step 6, money lane, without AI)
Transactions (income, expense, transfer), categories with colors, repeating transactions generated on demand, budgets per category per month, savings goals, monthly report with charts.
