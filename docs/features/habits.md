# Habits

## Purpose
Build and track habits.

## Screens
- Habit list with today's check-ins.
- Habit detail: streak, history calendar, statistics (week, month, year), notes.
- Create or edit habit.

## Features
Custom habits, daily/weekly/custom schedules, streaks, completion tracking, history, calendar view, statistics, categories, reminders, goals, notes.

## Actions
habits.list, habits.log, habits.stats

## AI
- Insights such as "Why have I been missing my workout habit recently?" using habit logs, calendar, and tasks.
- Recommendations for better times or smaller goals.
- Warns in the activity feed when a streak is at risk.

## Done when
I track all habits daily and the AI explains my patterns.
