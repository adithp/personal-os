# Wallet

## Purpose
Know where my money is.

## Screens
Wallet list with balances, wallet detail with balance history chart, transfer between wallets.

## Features
Cash balance, account balances, wallets, payment methods (cash, bank, card, UPI), transfers, balance history, spending overview. Balances update from Finance transactions.

## Actions
wallet.balances, wallet.transfer

## Done when
Balances match reality and transfers update both wallets.

## Built (Step 6, money lane)
Wallets (cash, bank, card, upi, other) with an opening balance; the balance is computed from transactions; a transfer is a transaction of kind transfer and shows on both wallets; wallets with transactions are archived, not deleted. Not built: balance history chart. See [money.md](money.md).
