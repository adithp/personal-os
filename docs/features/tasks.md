# Tasks

## Purpose
Manage daily tasks and long-term goals.

## Screens
- List view with grouping (by date, project, priority, tag).
- Kanban view (todo, doing, done) with drag and drop (dnd-kit).
- Calendar view (Schedule-X) showing tasks by due date.
- Planning view: today, this week, this month.
- Task detail panel: title, description, subtasks, priority, due date, reminder, recurrence, project, tags, dependencies, links.
- Archive.

## Features
Create, edit, delete, subtasks, priorities 1–4, deadlines, reminders, recurring (RRULE), dependencies (blocks links), categories, tags, filter, sort, search, archive.

## Actions
tasks.list, tasks.get, tasks.create, tasks.update, tasks.complete, tasks.delete, tasks.prioritize

## AI
- Organize tasks into projects and tags.
- Suggest tasks from emails, notes, and projects.
- Prioritize by deadline, dependencies, and calendar free time.

## Done when
I manage all my tasks here, and the AI can create, update, and prioritize them from chat.
